# 1.7B 실기기 피드백과 음성 표현 방향

현재 기준 버전은 `0.1.0-alpha3`, 모델은 `Qwen3-TTS-12Hz-1.7B-CustomVoice / Sohee`다. 이 문서는 사용자가 제공한 실기기 평가와 후속 요구사항을 기록한다. 앱 동작이나 모델 기본값을 변경한 릴리스 기록은 아니다.

## 확인된 실기기 기록

사용자 제공 JSON과 WAV를 확인했다. 기기는 SM-S948N, Android API 37이며, CPU 4스레드 / F16 + F32 CP-down / buffered 합성 / seed 42 조건이다. 말투 지시는 `차분하고 다정하게, `였다.

| 항목 | 측정 |
| --- | ---: |
| 생성 시간 | 53,457.28ms |
| 출력 오디오 길이 | 12.16초 |
| RTF | 4.396 |
| 첫 PCM 준비 | 53,462.50ms |
| WAV 수신 | 53,471.24ms |
| 첫 출력 타임스탬프 | 53,670.32ms |
| 관측 최대 worker PSS | 5,244,360KiB ≈ 5.00GiB |
| 재생 오류 | 없음 (`playback_error=null`) |

WAV는 24kHz / 모노 / PCM16 / 291,840 samples다. RMS가 0보다 크고 샘플 포화는 없었다. 첫 출력은 Android AudioTrack 타임스탬프 기준이며 스피커에서 귀까지의 물리적 지연을 측정한 값은 아니다. PSS는 관측값이며 장시간 최대 메모리나 발열 검증을 뜻하지 않는다. 12.16초 음성 대비 생성 53.46초가 걸려 실시간보다 약 4.40배 느렸다.

사용자 청취 점수는 **발음 4/5, 억양 3/5, 리듬 3/5**다. 사용자는 0.6B보다 억양과 말투의 자연스러움이 전반적으로 좋아졌다고 평가했다. 앞선 0.6B 평가는 발음 4/5, 억양 2/5, 리듬 2/5였지만 입력 문장과 말투 조건이 같지 않아 통제된 A/B 비교는 아니다. 이 점수는 사용자 청취 평가이며 에이전트가 직접 청취해서 판정한 점수가 아니다.

개인 기기의 전체 fingerprint, 원본 평가 JSON, 첨부 음성 파일과 원문 발화는 저장소에 복사하지 않는다. 표의 비식별 측정 요약과 개발 방향만 기록한다.

## 합의된 우선순위

- 1.7B Sohee를 현재 음질 개선의 기준선으로 삼고, 0.6B 선택 기능도 유지한다.
- 반응 속도 문제는 후속 업데이트 또는 데스크탑 PC 중앙 서버 연결 과제로 둔다. 속도를 위해 현재 음질을 임의로 낮추지 않는다.
- OpenAI API 연결은 향후 검토 대상이다. 아직 API, 서버, 인증, 네트워크 권한을 추가하지 않는다.
- 대화 내용을 생성하는 계층과 Sohee로 음성을 합성하는 계층은 분리한다. 향후 대화 API 채택만으로 로컬 TTS의 생성 지연이 해결된다고 가정하지 않는다.
- 데스크탑 서버는 실제 하드웨어와 부하를 측정한 뒤 판단한다. 서버 연결 시 오프라인 모드와 네트워크 모드를 명확하게 구분하는 설계가 필요하다.

## 호흡과 비언어 표현

**발화나 문장 시작마다 들이마시는 소리를 반드시 넣지 않는다.** 호흡은 말의 흐름과 감정을 전달하는 표현 수단으로 사용한다.

| 상황 | 목표 동작 |
| --- | --- |
| 일반적인 짧은 답변 | 과장된 선행 들숨 없이 자연스럽게 말하기 |
| 이어서 말하는 경우 | 문장·청크마다 새 들숨을 반복하지 않기 |
| 빠른 템포의 대화 | 호흡·불필요한 간격을 최소화하고 흐름 유지 |
| 긴 발화 | 의미 단위의 적절한 경계에서 자연스럽게 호흡 |
| 사용자 대답에 따른 감정 반응 | 맥락에 필요한 경우에만 숨, 한숨 등 비언어 표현 사용 |

현재 앱 코드는 `engine->synthesize`의 출력 PCM을 WAV로 저장하고 그대로 재생한다. 별도의 호흡 음원을 문두에 삽입하는 기능은 없다. 모델이 생성한 호흡과 잡음, 첫 자음은 별도 청취·음향 분석으로 구분해야 한다.

문두를 일정 길이로 자르거나 RMS 임계값만으로 제거하는 방식은 적용하지 않는다. 첫 자음·음절, 자연스러운 약한 발성까지 손상할 수 있다. 모든 호흡을 없애는 것도 목표가 아니다. 현재 Voice Lab에는 사용자의 대답을 이해하는 대화 계층이 없으므로 맥락 기반 감정·호흡 선택은 아직 구현되지 않았다.

## 다음 검증

첫 비교 실험의 15개 음성을 생성했다. 조건, 측정 결과와 청취 절차는 [호흡 표현 비교 01](BREATH_STUDY_01.ko.md)에 있다. 청취 평가와 휴대전화 재현은 아직이며 기본값을 변경하지 않았다.

1. 같은 텍스트·모델·seed로 말투 지시가 없는 경우와 호흡을 절제하는 지시를 비교한다. 문장 길이, 문장부호, 줄바꿈 등 다른 조건은 유지한다.
2. 일반 답변, 연속 발화, 빠른 템포, 감정 반응 문장을 각각 청취한다. 문두 호흡의 반복 여부와 첫 발음 보존을 함께 평가한다.
3. 아래 지시는 실험 후보이며 기본값으로 적용하거나 효과를 보장하지 않는다.

   > 친한 친구와 대화하듯 또렷하고 자연스럽게 말해 주세요. 매 문장 시작에 과장된 들숨을 반복하지 말고, 필요한 의미 단위의 경계에서만 가볍게 호흡해 주세요.

4. 개선이 확인된 지시나 생성 방식만 기본 음성 정책에 반영한다. 필요하면 추후 대화 계층에서 발화의 연속성·속도·감정 정보를 음성 엔진에 전달하는 구조를 검토한다.
5. 속도 개선·PC 서버·대화 API 연결은 별도 구현 및 검증 작업으로 진행한다. 이번 피드백 기록만으로 해당 기능이 구현된 것은 아니다.
