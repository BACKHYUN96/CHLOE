## GPT 직접 평가 방식

모델 신원을 두 무작위 라벨로 가린 실제 문맥/응답을 직접 읽고, 전체 문맥/기준/응답이 정확히 같은 그룹만 하나의 명시적 판정을 확장한다. 전체 판정을 고정한 뒤 대응표를 연다. 조건·예상 소유자는 보이고 같은 GPT가 작성/평가한 알려진 형식·단일 seed라 완전 블라인드/독립 평가는 아니다. 정확한 GPT 배포 revision은 세션에서 노출되지 않는다.

소유자 태그는 user/assistant/third_party/other다. 이름을 자기소개한 사용자와 별도 제3자를 구분하며, 소유자 생략/모호한 우리 집/출처 없는 인용을 정답으로 올리지 않는다. 소유자만 맞아도 대상·이름/색/관계가 틀리면 memory pass가 아니다. 엄격 통과는 말투·관련성·자연스러움·기억·정직성 모두 pass와 앱 계약/EOS가 필요하다. 출력 regex/외부 judge API로 품질을 채점하지 않는다. 원문/개별 판정/대응표는 Git 제외 로컬 자료에 둔다.

## 원인 범위와 다음 개선

1. **인칭 귀속 실패가 새 물건에도 나타난다.** 고양이 대화만의 특수 현상은 아니다. 이름을 알고도 내를 assistant 소유로 답하는 문제와, 구체 이름을 소유 관계로 연결했을 때 개선되는 경우가 함께 관찰됐다.
2. **표현의 효과는 소재에 의존한다.** 나비/지연은 이름 소유격으로도 실패했다. 나비야를 별도 이름/주체처럼 다루거나 소유 대신 이름을 반복하는 응답이 보였지만, 종/이름/인명/구문을 완전 교차하지 않았으므로 토큰화/어미 분리/이름 자체 중 무엇이 원인인지는 확정하지 않는다. 이전 민수/보리의 성공을 보편적인 이름 재작성 규칙으로 채택하지 않는다.
3. **역할명과 명시적 이름의 우열도 고정되지 않는다.** 새 자료의 사용자의는12/16으로 이름의10/16보다 소유자 정답이 많았으나 앞선 자료와 양상이 다르다. 이름 소유격의 한 가지 성공을 유일한 개선책으로 고르지 않는다. 소유자만 맞고 경험을 꾸민 답·말투 실패도 별도다.
4. **재학습/모델 교체 판단은 유보한다.** 두 모델의 핵심 이름 쌍 결과는 같고, 전체 주 비교와 가상 대조에서 엄격 통과 우세 방향도 다르다. 같은 GPT 작성자/평가자·소수 합성 사례·단일 seed이므로 일반 우승/실사용 품질 이득으로 확장하지 않는다.

다음 후보는 같은 인명을 유지한 동물명 교환, 같은 동물명에서 종/인명 교환, 물건 문장의 구문을 동물 사실과 맞춘 대조, source가 명시된 사실 표현과 독립 질문/평가다. 더 긴 실제 자기 생성 대화·이름 충돌·다른 대상·폰 실측도 미완료다. 이번에 추가 prompt/제품 이력 정책을 구현하거나 재학습하지 않았다.

PocketPal에서 긴 답변이 나온다는 사용자의 관찰은 별도 [공개 소스 비교](pocketpal-source-review-report.md)에 분석했다. 사용자 보고4B Q4_0과 이번 PC2B NF4, CHLOE220자 발화 계약/384토큰과 PocketPal 조사 소스의 생성 기본값은 서로 다르다. 앱 소스가 더 좋은 소유자 귀속을 보장한다고 결론짓거나 이번 실험을 PocketPal 성능 평가로 부르지 않는다.
