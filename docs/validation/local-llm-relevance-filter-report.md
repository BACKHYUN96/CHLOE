# 필요한 사용자 사실 보존 · PC 실제 전후 비교 · 2026-11-15

**관련성 필터가 필요한 사용자 원문을 생략하던 결함을 수정했다.** 같은 질문과 실제 이어지는 대화로212개 응답을 새로 생성했다. 연속30턴은 통과13→15, 부분8→9, 실패9→6이며 등급 상승3·하락0이다. 기존54개와 독립20개 결과는 유지됐다. 실제 모델 입력의 누락은 고쳤지만, 근거를 보고도 제작자를 모른다고 하는 첫 회상과 이름 되묻기는 남았다.

기존4B·2B 원본·10-step adapter·학습 환경·폰79개 기록을 보존했다. 재학습·adapter 적용·모델 교체·폰 설치·PR 병합은 없다. 제품 소스 변경은 `GroundedConversationPolicy`의 **이력 관련성 판정과 보조 함수**뿐이다. 이전 소스는 snapshot으로 보존했다.

## 바뀐 동작

이전에는 명확한 관련성 표현을 찾지 못하면 사실 발화와 중립 확인 답변을 model view에서 생략했다. 예를 들어 “제가 만든 앱 이름은 별담이에요.”가 원래 이력에 있어도 “별담을 만든 사람은 누구인가요?”에서 이름 어미가 모호하고 `앱`이라는 단어가 없다는 이유로 근거가 빠졌다.

이제 **관련성 불확실성을 생략 근거로 쓰지 않는다.**

- 이름 지칭, 제작자/소유자 회상, 정리/구분, 불분명한 대명사가 있으면 원문을 보존한다. 서로 다른 사실을 정리하는 질문에서도 원래 발화 순서를 유지한다.
- 모호한 `이야/이에요`의 이름 후보는 검색 단서로만 사용한다. 원문을 보존할 뿐 이름을 확정하거나 구조화 사실/정답으로 새로 승격하지 않는다.
- 명시적 제외는 지칭한 화제/이름에 적용한다. 하나를 빼 달라는 말을 이유로 다른 사실 원문까지 전부 생략하지 않는다.
- 명확히 다른 사실 화제, 짧게 말하기/인사, 내부 규칙 요청, 독립적인 용어 설명 등은 기존의 무관한 사실 억제를 유지한다. 판단할 수 없으면 보존한다.

`RELEVANCE_VERSION=preserve-uncertain-source-v1`이다. **사실 추출·구조화 데이터의 관련성 선택·creator hint·최종 근거 답변·대화 동작·economy·integrity·기본 persona·기억창 제한은 바꾸지 않았다.** 특히 구조화 데이터의 제외 처리를 전반적으로 새로 설계한 것이 아니라, 원래 user/assistant 쌍의 model view 생략 범위를 수정했다. 원본 세션이나 디스크 기록을 삭제하지 않는다.

## 실행 조건·판정·보존

4B는 기존 **Qwen3.5-4B Q4_K_M**,2,740,937,888바이트, SHA `00fe7986ff5f6b463e62455821146049db6f9313603938a70800d1fb69ef11a4`다. 기존2B adapter를4B에 적용하지 않았다. 평소 PocketPal의 Q4_0과도 구분한다. 같은 기존 격리 WSL CUDA worker, engine source `aa75ff3239f9cc675b081697deda9e1b112345c6`, thinking=false/temp0/seed42/context2048/max384/threads4, 실제33/33 레이어 offload다. 설치·다운로드·native 재빌드는 없다.

기존54개는 직전의 고정 system, 새20개/대화는 현 실제 `PersonaManager.system`이다. system은 **각 집단의 전후에 동일**하지만 집단 간 다르므로 집단 간 점수 차이를 문맥 효과만으로 해석하지 않는다. 이전 최소 경로 실험과 이번 필터 전후 실험의 기준선도 구분한다.

GPT가 내용·말투·정직성·정체성/역할·문맥·지시 처리 기준으로 실제 원문/최종 발화를 판정했다. 기존과 정확히 같은 질문/원래 이력/발화는 출처를 표시해 판정을 재사용했다. 새롭게 다른 문맥/발화6그룹은 직접 읽어 고정했고, 같은 문맥/발화인 원문·최종·보조 질문은 같은 판정으로 묶었다. 자동 exporter는 의미 점수를 만들지 않는다. 이전 오류를 보고 작성한 개발 개선이며, 알려진 질문·조건을 아는 작성자 평가다. 사람/독립/블라인드/holdout 평가가 아니다.

원본4B·WSL2B·adapter SHA, 기존 training pip freeze/시스템 package 목록, 폰79개 JSONL SHA가 일치한다. 이번 폰 명령0회이며 원본 기기 APK/설정/로그의 현재 해시는 재검사하지 않았다. 모델·checkpoint·jar·SDK·개인 로그는 Git에 추가하지 않았다.

## 남은 문제와 다음 경계

필요한 원문을 남기는 것은 **정보를 읽고 정확히 추론하는 능력의 보장**이 아니다. 앱 제작자를 알려 주었는데도 모른다는 첫 회상, 이름을 구분한 뒤 다시 모호하게 묻는 문장, 다른 대화의 주체/감정·의미 반복·지식 오류가 남는다. 이번에는 그 실패를 없애기 위한 새 고정 답변이나 추가 system 지시를 넣지 않았다.

다음 후보는 이름 어미 확정과 분리된 명시적 제작 관계의 회상, 사용자 근거와 assistant 추측의 구분이다. 필터 변경과 별도 요소로 비교해야 한다. 기본 보존 범위를 넓힌 만큼 보지 않은 화제에서 사실이 다시 끼어들 가능성과 더 긴 대화/다른 이름·seed는 추가 검증 대상이다. 실제 Android 제품 APK/UI/TTS·원본 앱 업데이트·장기 기억은 미검증이며 이번 PC 결과를 폰 성공으로 승격하지 않는다.
