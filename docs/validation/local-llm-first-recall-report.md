## 원인 범위와 남은 개선

이번에 좁힌 범위는 **현재 고정 prompt/runtime 아래에서 소유 관계를 발화자·인칭 시점에 연결하는 데 취약하고, 구체 이름 소유격과 일반 역할명/인용/인칭 표현의 처리 양상이 다르다**는 것이다. 선행 assistant 오답·긴 문맥·연속 user 역할·회상 질문의 모호성 중 어느 하나도 단독 설명으로 충분하지 않다. 앞선 누적 모순의 후속 영향과 이번 최초 귀속 오류는 함께 존재할 수 있다.

내부 attention/표상, pretraining 또는10-step 학습 결함, 특정 라이브러리 결함을 출력만으로 확정하지 않는다. 원본과 adapter 모두 같은 핵심 실패를 보여 adapter만의 문제로 볼 근거도 부족하다. adapter의 주 비교 정답2개/엄격 통과2개 차이는 작은 알려진 세트·같은 GPT 평가이며 일반적인 우승이나 모델 승격을 뜻하지 않는다. 모델·system을 바꾸는 개선책은 이번에 적용하지 않았다.

다음 검증 후보는 미사용 인명·동물명/다른 소유 대상, 동일 명사구를 유지한 다양한 인칭/인용 형식, 명시적 화자 식별과 사용자 사실 출처를 보존하는 이력 표현이다. 이름으로 풀어 쓰는 방식이 타인 사실/이름 충돌/한국어 자연스러움에 미치는 퇴행까지 확인해야 한다. 현재 한 인명·한 고양이 이름의 성공을 자동 재작성 정책으로 채택하지 않는다. 독립 평가·새 질문·자기 생성 rollout·실기기 검증은 미완료다. 재학습은 수행하지 않았다.
