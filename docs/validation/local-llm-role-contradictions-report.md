## 원인 범위와 다음 개선

1. **발화 주체 귀속을 우선 분리 검증한다.** 중립/사용자 전용에서도 모델 소유 오답이 있고 최초 회상은 선행 명시적 소유자 오답 없이 실패한다. 다음 후보는 첫 사실 제시→첫 회상만의 짧은 쌍에서 사용자/assistant 주체와 소유어 표현을 대조하는 것이다. 새로운 정답을 system에 주입한 것과 구분해 평가해야 한다.
2. **최신 정답 하나로 모든 이전 모순을 덮는 정책은 불충분하다.** 반말 요약에서 오래된 모순도 영향을 줬다. 이후 이력 교정 후보는 사용자 사실의 출처를 보존하고 충돌한 assistant 주장 전체를 추적하는 방식으로 검증하되, 오류 개수와 위치·질문·말투를 별도 고정한다. 이번에는 제품 정책을 구현하지 않았다.
3. **소유자 정확성과 현재 요청 선택을 별도 평가한다.** 전체 소유어 교정 후에도 화제 침입4/8이 남았다. 중립의 반복 제거 효과를 바탕으로, 다음에는 반복 화제 표현과 현재 요청 선택을 분리한 실험이 필요하다. 소유어 교정만으로 관련성 문제가 해결되었다고 보지 않는다.
4. **재학습 판단은 유보한다.** 알려진46질문·단일 greedy seed·같은 GPT 평가에서 원본/adapter의 누적 교정 성과는 같았다. 독립 질문/다른 사실/독립 평가 검증은 미완료이며 일반 품질 우승·adapter 승격을 주장하지 않는다. 무이력 자기소개/정직성 오류도 남는다.
