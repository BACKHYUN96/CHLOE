## 구현과 검증 범위

`ConversationManager.accept`에서 기존 JSON 소비/사실 정책 뒤 정리하고, 최종 발화를 대화 이력과 TTS 호출자에게 반환한다. `economyAction`을 기존 `policyAction`과 분리해 기록한다. 연속된 동일 문장/최대4문장 블록, 긴 네/응/예/음 채움말 반복을 삭제하며, 충분한 본문 뒤의 제한된 일반 초대·도움 질문·이름 질문·재설명 제안만 삭제한다. 새로운 사실이나 문장은 만들지 않는다.

인용·코드·URL·명시적 반복/질문 요청·필요한 확인·모른다는 응답·문장 수 조건을 보존한다. 일반적인 의미 중복이나 모든 무관한 질문을 판별하는 장치는 아니다. 사용자 질문의 역할이나 주체를 재작성하지 않는다. 무효/빈 모델 출력은 복구하지 않는다.
