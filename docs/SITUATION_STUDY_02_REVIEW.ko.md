# 수정 비교 02 청취 평가와 다음 기준

이번 기록은 사용자 청취 평가와 웃음 표현에 대한 추가 답변을 반영한다. 에이전트의 직접 청취 점수나 새로운 음성 생성 결과가 아니다. 원래 생성 측정 JSON은 그대로 보존하고 [청취 판정 JSON](validation/situation-study-02/listening-feedback.json)을 별도로 둔다.

## 유지할 표현과 수정할 표현

- explanation_01_C: 힘이 없는 인상을 개선한다. 담담함과 발성의 생기를 별개로 평가한다.
- explanation_02_C: 정보 전달보다 친근하게 권유하는 문장이다. 들어보세요의 부드러운 상승·여운과 돼요의 웃는 느낌을 허용한다. 설명 전체를 낮고 건조하게 통일하지 않는다.
- explanation_03_C: 전반적인 말투는 보존 후보. 시간이에요 → 오디오 길이와 비교하면 사이에 들숨을 넣지 않고 부드럽게 이어가는 것이 핵심이다.
- surprise_01_C: 차분한 공감형으로 합격. 오와 진짜의 하강도 맥락에 맞으며 후속 질문의 끝음을 억지로 올리지 않는다.
- surprise_02_C: 전반적 개선을 인정하되 빠른데라는 마지막 단어만 상승하도록 목표를 좁힌다.
- surprise_03_C: 정제되고 어색한 표현으로 제외한다. 앞선 복합 감정 지시가 성공했다고 간주하지 않는다.
- surprise_03_D: 신규 중 가장 좋은 차분한 후보. 잠깐 → 잠깐만을 우선 한 글자 변경으로 비교해 차가운 인상을 완화한다.

참고 음성은 REF_surprise_01_A와 REF_surprise_02_A가 각각 4.5/5로 합격, REF_surprise_01_B는 4.5/5 수준으로 합격에 근접한다. B의 첫 감탄사는 A처럼 덜 눌린 표현이 목표다. REF_explanation_03_A도 전반적으로 괜찮으며 알 수 있어요의 웃는 느낌과 여운을 후속 목표로 둔다. 사용자 점수가 없는 음성에 임의 점수를 부여하지 않는다. 이번에 다시 언급되지 않은 REF_surprise_03_A/B는 이전 개별 평가를 유지한다.

## 상황과 표현을 분리

설명이라는 분류 하나로 종결 억양을 고정하지 않는다. 정보 설명은 생기 있는 담담함과 연속성, 친근한 권유는 미소·적당한 상승·여운을 목표로 한다. 차분한 공감은 낮은 억양도 허용하고, 감탄은 해당 단어 또는 구절에 필요한 만큼만 표현한다.

사용자는 (웃음)을 상황에 따라 **미소가 섞인 목소리와 실제 짧은 웃음 모두**로 설명했다. 두 항목을 분리해 비교하며 미소 지시가 실제 웃음 소리를 생성한다고 가정하지 않는다. 실제 웃음의 생성·삽입 기능은 구현하지 않았다. ↗↘는 억양 방향, ?, !, ~의 반복은 말투·감정의 표현으로 기록한다.

## 다음 검증 순서 — 아직 미실행

1. 합격한 surprise_01_C와 점수가 좋은 참고 음성은 기준으로 유지한다.
2. explanation_01은 발성의 생기, explanation_02는 권유의 미소, explanation_03은 지정 경계의 호흡을 각각 별도 목표로 비교한다. 미소가 섞인 권유와 실제 짧은 웃음은 다른 조건으로 나눈다.
3. surprise_02는 동일 원문으로 마지막 단어의 억양만 바꾸는 지시 후보를 비교한다.
4. surprise_03_D의 원문 잠깐,을 잠깐만,으로 바꾸고 나머지 지시·글자·문장부호·모델·seed·샘플링은 유지한다. 말줄임표 추가는 한 글자 변경 효과와 섞이지 않도록 별도 조건으로 둔다.
5. 훨씬 빠른걸 같은 대사와 사용자가 제안한 더 생생한 감탄 문장은 별도의 입력 문장 실험으로 취급한다. 같은 문장의 억양 개선 결과와 합산하지 않는다.
6. 위 후보를 다시 듣고 난 뒤 채택한 말투로 여러 문장 연결과 문장 경계의 호흡 반복을 검사한다. 현재 자료만으로 연속 대화가 검증됐다고 판단하지 않는다.

사용자의 청취 인용과 원본 입력이 다른 부분은 임의로 원문을 고치지 않는다. 예를 들어 원문은 차례로와 오디오 길이와 비교하면이며, 청취 인용의 차례대로·오디오 끼리만으로 확정된 단어 오류라고 판정하지 않는다. 필요한 경우 해당 구간을 재청취한다. 감정과 억양 지시가 원하는 파형·길이를 정밀하게 보장하지 않으므로 최종 판정은 청취와 발음 보존 확인을 따른다.

## 이번 변경 검증과 범위

원격 생성 기록의 신규 7개와 참고 6개를 읽고, 평가 대상 신규 7개·참고 4개의 ID 일치와 중복 없음, 사용자 명시 점수 3개(각 4.5/5), JSON 왕복 파싱을 확인했다. 변경 텍스트의 후행 공백과 문서 연결도 검토했다.

이번에는 평가 문서와 JSON만 변경한다. 작업 환경 셸 연결 실패로 git diff --check와 로컬 검증 명령은 실행하지 못했다. Android 빌드·기기 테스트·재합성은 수행하지 않았으며 앱 기본값·모델·원본 WAV는 변경하지 않았다.
