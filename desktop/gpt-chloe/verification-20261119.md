# GPT 클로이 PC 앱 실행 검증 · 2026-11-19

PC 브라우저에서 한국어 스트리밍 대화, 장기 기억 편집, 말투 피드백·예시 저장, API 키 설정을 실행했다. 사용자가 키를 등록한 뒤 실제 OpenAI 응답을 생성했다. 별도 작업 폴더와 `feat/gpt-companion` 브랜치를 사용했고 변경 파일은 `desktop/gpt-chloe/`에 한정된다.

## 실제 API 비교

합성 6문항을 같은 기억·말투 지침으로 세 모델에 요청했다. 각 문항은 새 세션이며 정정 문항에서만 제작자 기억을 사용자에서 민지로 바꿨다. 18개 모두 정상 완료했다. 시험은 모델별로 순차 실행했고 한국어 한두 문장의 짧은 답변을 주로 포함한다. 이번 시간 측정은 한 회차·6개 표본으로 모델의 일반적인 속도를 확정하지 않는다.

GPT가 모든 실제 발화를 직접 읽어 일상 대화, AI 정체성·거주지 정직성, 같은 앱 회상, 다른 앱 구분, 정정 반영, 알람 실행 한계를 확인했다. 개발자 평가이며 블라인드 평가와 장기 대화 검증은 별도로 남아 있다. [실제 18개 발화와 측정값](verification-20261119.json)

Terra는 “새아라 만든 이가 누군지 떠올라?”에 “응, 네가 직접 만들었다고 했어.”라고 답했다. “그럼 아라 앱은 어느 개발자 손에서 나왔어?”에는 아라의 개발자를 모른다고 답했다. Sol도 두 대상을 구분했다. Luna는 아라를 물었을 때 새아라를 사용자가 만들었다고 답해 대상 구분에 실패했다.

Terra의 일상 대화 답변은 “그럴 땐 그냥 쉬어도 돼. 오늘은 밥만 대충 챙겨 먹고 푹 쉬자.”였다. 실제 서울에 산다고 주장하지 않았고, 알람을 맞췄다고 답하지 않았다. 기본값으로 Terra를 선택했다. 사용자 계정에서 세 모델의 목록 접근과 생성이 모두 확인됐다.

## 실제 브라우저 검증

시험용 서버 8769번에 별도 DB와 메모리 전용 키를 사용했다. 실제 사용자용 서버는 8768번이다.

1. 기억 화면에 합성 앱 새아라를 저장하고 제작자를 민지로 정정했다. 새로고침 후 수정한 기억이 표시됐다.
2. 말투 학습실에 짧은 공감과 불필요한 되묻기를 줄이는 피드백, 질문·답변 예시를 저장했다. 새로고침 후 자료가 표시됐다.
3. 실제 화면에서 “새아라와 아라의 제작자가 각각 누구였는지 기억해?”를 보내자 “응, 새아라의 제작자는 민지야. 아라는 다른 앱이고, 제작자는 알려지지 않았어.”라고 답했다.
4. 이어서 현재 대화에만 따뜻한 보리차 취향을 알려 주고 회상을 요청하자 “따뜻한 보리차를 더 좋아하신다고 하셨어요.”라고 존댓말 요청까지 반영했다.
5. 새 세션에서 앱 제작자와 음료 취향을 묻자 “새아라 제작자는 민지라고 기억해. 네가 좋아하는 음료는 저장된 기억에 없어서 모르겠어.”라고 답했다. 저장한 장기 기억과 해당 세션 대화 이력의 전달 범위를 확인했다.
6. 브라우저 개발 로그에서 JavaScript 오류 0개를 확인했다. 사용자용 말투 학습실을 실제로 열어 전달했다.

브라우저 4회 추가 호출까지 총 22회가 완료됐고, 추정 총비용은 **$0.0162686**이다. 사용자 계정 전체 사용액과 잔액은 이 수치에 포함하지 않는다. 실제 답변·토큰·시간을 검증 JSON에 보존했다.

## 자동 검사와 한계

단위검사 9개가 통과했다. 기억 정정·삭제·재시작 보존, 예시와 설정의 실제 요청 반영, 스트림 정상 완료의 원자적 저장, 중복 요청 거부, 미완성·끊긴 응답의 이력 제외, 키 누락 처리, 완전한 대화 쌍의 길이 제한, Windows DPAPI 암호화 왕복, HTTP Host·Origin·변경 토큰·키 비노출을 검사했다. 첫 HTTP 검사는 샌드박스 소켓 제한으로 실행할 수 없어 권한을 받아 같은 검사를 다시 수행했다.

JavaScript 구문 검사와 Git 공백 검사를 통과했다. 실행 파일을 통해 서버를 백그라운드로 띄우고 기본 브라우저가 열리는 것을 확인했다. 별도 Python 패키지는 설치하지 않았다.

장기 기억은 사용자가 명시적으로 추가·수정하는 방식이다. 말투 학습은 저장된 지침과 예시를 요청에 반영한다. 모델 가중치 변경과 파인튜닝 작업은 0회다. 긴 대화의 다양한 화제 전환과 모델 오류 전반, 음성 입출력, Android 적용은 이번 검증 범위 밖이다. 네트워크 중단·요금 한도 등의 실제 OpenAI 장애 상황은 직접 유발하지 않았고, 실패 스트림 동작은 단위검사에서 확인했다.
