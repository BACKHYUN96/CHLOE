# 잡담·말 이어가기·조언 요청 블라인드 비교

기준은 `15d3912`의 GPT PC 앱이다. 비교 후보는 같은 서버의 PERSONA 마지막 문장 앞에 [추가 지침](intent-candidate.txt) 한 문단을 삽입했다. 실제 사용자 DB와 분리한 합성 세션에서 Terra가 응답했다.

사용자 발화, 의도, 채택 기준을 [시험 묶음](intent-suite.json)에 먼저 고정했다. 각 대화는 버전별로 새 세션에서 시작하며 해당 버전이 실제 생성한 답을 다음 문답의 이력으로 쓴다. S는 이야기를 나눔, C는 이어서 말함, A는 도움을 요청함이다. 의도에 맞는 반응과 사실 정확성을 우선하고 한국어 말투와 요청 형식까지 직접 읽어 비교한다. 실질적인 차이가 작거나 양쪽 결함의 경중을 가리기 어려우면 동률이다.

평가자에게는 사용자 발화와 익명 답변 A/B만 제시했다. 대화마다 무작위로 대응표를 정하고 같은 대화 안에서는 대응을 고정했다. [판정](intent-ballot.json)을 파일로 저장한 뒤 버전을 공개했다. [해제된 응답·비용](intent-results.json)에서 모든 선택과 이유를 확인할 수 있다. 단일 AI가 구현과 평가를 맡았으며 각 장면은 한 번 실행했다. 이어지는 턴 사이에는 의존성이 있다.

채택 기준은 후보 선호가 기존 선호보다 전체에서 많고, 각 의도별로도 후보가 기존보다 밀리지 않는 것이다. 최대 비용은 실행당 $0.96으로, 두 실행 합계 $1.92로 제한했다. 매 요청 전 최대 출력과 입력 크기를 포함한 예약 비용을 검사한다. 자동 재시도는 없다.

| 의도 | 후보 선호 | 기존 선호 | 동률 |
| --- | ---: | ---: | ---: |
| 이야기 나눔 | 3 | 1 | 3 |
| 말 이어가기 | 1 | 0 | 5 |
| 조언·도움 요청 | 1 | 1 | 3 |
| 합계 | 5 | 2 | 11 |

후보가 채택 기준을 충족했다. 리본을 꺼내다 뭘 발견했냐는 말줄임에 후보는 “응응.”으로 차례를 넘겼다. 스티커를 뗄지 말지 묻자 재질별 선택지를 바로 제시했다. 반면 공연 좌석 교환에서는 기존의 시야 확인 안내가 후보보다 구체적이었다. 동생이 한 말을 전하려던 장면에서는 양쪽 모두 똑같이 되물었다. 노래방 이야기를 마칠 때 후보가 노래를 부르기 전에 서비스를 받았다는 순서를 보탠 것도 결함이다. 동률은 오류 없음이나 완벽한 의도 분류를 뜻하지 않는다.

요청은 36회 모두 완료했다. 입력 38,899토큰, 캐시 입력 18,704토큰, 출력 1,045토큰, 추정 비용 $0.02635520(기존 $0.01992740, 후보 $0.00642780). 이번에 지정한 $1.94 한도에서 약 $1.9136이 남았다. 버전별 입력 캐시 적중량 차이가 크므로 비용 차이를 일반화하지 않는다. 자동 검사 15개 통과. 기본 GPT 앱에는 실제로 평가한 후보 소스를 사용했다.
