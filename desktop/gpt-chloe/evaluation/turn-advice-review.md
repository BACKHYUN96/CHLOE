# 말을 잇는 신호와 구체적인 조언 요청

기준은 `bba38e2`의 GPT 클로이 PC 앱이다. [후보 지침](turn-advice-candidate.txt)을 기준 PERSONA 끝의 한국어 본문 지시 직전에만 추가했다. 일상의 독립적인 6개 상황에서 각 3턴을 진행했다. 첫 턴은 상황 소개, 두 번째는 미완성 발화, 세 번째는 조건이 있는 조언 요청이다. [사용자 발화와 채택 기준](turn-advice-suite.json)을 생성 전에 고정했다. 양쪽 모두 Terra 기본 설정으로 버전별 자기 응답을 이력에 사용했고 사용자 데이터 대신 임시 DB를 사용했다.

각 대화에 독립적으로 A/B를 무작위 배정했다. 버전과 메트릭을 숨긴 원문만 읽고 [선호와 이유](turn-advice-ballot.json)를 저장한 뒤에 대응표를 열었다. 사용자 발화 의도·맥락·정확성, 바로 쓸 수 있는 정도와 자연스러움을 검토하고 유의미한 우열이 없으면 동률로 평가했다. 말 잇기 및 조언 요청 양쪽 모두 후보 선호가 기존보다 많고, 전체에서도 우세해야 적용하기로 했다. 후보를 만든 단일 AI의 블라인드 선호이며 독립 사람 평가나 일반 성능 수치는 아니다.

[모든 실제 응답, 선호와 토큰·비용](turn-advice-results.json). 호출 전 최대 예상 비용을 검사하며 두 버전의 추정 한도는 각각 $0.95, 전체 $1.90이다.

| 구분 | 후보 선호 | 기존 선호 | 동률 |
| --- | ---: | ---: | ---: |
| 상황 소개 | 2 | 2 | 2 |
| 말 이어가기 | 3 | 0 | 3 |
| 조건이 있는 조언 요청 | 1 | 0 | 5 |
| 전체 | 6 | 2 | 10 |

말 잇기에서 질문형으로 되받은 횟수는 기존 3/6, 후보 0/6이었다. 조언 6건 모두 양쪽에서 실행 가능한 답을 얻었다. 책 상자를 쌓는 장면에서만 후보가 표시한 면을 바깥으로 두라고 덧붙여 우세했다. 시간 배분은 두 답 모두 15초 안내를 유지하고 전체를 정확히 30초로 맞췄다. 상황 소개에서는 후보가 명찰을 다시 쓰자고 일찍 제안하거나 행사 정보를 먼저 요구한 사례가 있다. 각 조건의 우세와 전체 우세를 충족해 평가한 후보를 적용했다. 조언 우위는 한 쌍 차이이므로 다른 주제에서의 일반화에는 한계가 있다.

36회 완료. 입력 43,236토큰(캐시 포함 39,341토큰), 출력 863토큰. 기존 추정 $0.00374410, 후보 $0.00643295, 합계 $0.01017705. 이번 $1.91 예산 중 $1.89982295가 남았다. 이는 앱 단가로 계산한 이번 시험 비용이며 계정 잔액과 별개다.
