# GPT 클로이 긴 대화·새 질문 검증 — 2026-11-19

짧은 문답이 이어지면 초기 사실과 정정이 20문답 뒤에 요청에서 빠졌다. GPT가 전달받지 못한 내용을 부정하거나 오래된 장기 기억으로 돌아가는 것이 이번 시험의 가장 큰 오류였다. 문답 수 제한만 제거하고 기존 24,000자 한도, 모델, 페르소나, 장기 기억 방식은 유지했다. 한도 초과 시에는 이력이 일부 제외됐다는 사실을 모델에 제공한다. DB 원문과 사용자 기억을 삭제하거나 자동 수정하지 않는다.

## 조건과 평가 방식

- 기준 소스: `7177956a67a88b5ef34070ebf7780e10b6e6ef97`의 `server.py`. 수정 전후 LF 정규화 SHA-256과 질문 묶음 해시는 [사용량 집계](usage-summary.json)에 있다.
- GPT-6.1 Terra, reasoning none, max_output_tokens 4096, service_tier default, store false. API 키만 메모리에서 읽어 사용했고 개인 대화 DB는 평가 입력에 넣지 않았다.
- 수정 전 호출 전에 고정한 [32문답 + 새 단발 12질문](long-dialogue-suite.json)을 양쪽에서 모두 새로 생성했다. 각 조건은 자기 직전 실제 응답을 이력으로 사용했다. baseline 답변을 수정 후 이력에 재사용하지 않았다.
- 수정 후 소스를 고정한 뒤, 수정 후 응답을 읽기 전에 별도의 [새 26문답](heldout-dialogue-suite.json)을 작성했다. 사람·취미·물건 소유권 이전·인용문·말투 전환으로 확인했다. 확인 결과에 맞춘 추가 튜닝은 하지 않았다.
- 총 114개 완료 응답을 Codex가 직접 읽고 사실·주체·정정·정직성·한국어 말투·지시 준수를 평가했다. [문항별 판정과 주의점](manual-review.json). pass는 필수 조건 충족이지 완벽한 말투를 뜻하지 않는다. partial은 부분 결함, fail은 사실·회상·기능 설명 실패다.
- 비블라인드 단일 AI 평가이며 독립 사람 평가나 모델의 일반 성능 점수가 아니다. 표본당 1회 생성이므로 문장 차이와 시간 차이에 확률적 변동이 있다.

| long-31 관계 요약 | 사람·고양이 관계 누락, 제작자 오답 | 관계 정확, 불필요한 성별 대안 표현은 남음 |

위 6문항은 모두 실패에서 필수 조건 충족으로 바뀌었다. `long-25`에서 수정 전 전송 이력은 40개 메시지·1,746자였고 수정 후에는 48개·2,120자였다. 24,000자 한도와는 한참 떨어져 있어 원인은 길이 부족보다 20문답 제한이었다. 실제 전송 payload를 원문 파일에 보존했다. 회귀검사에서도 36개의 짧은 문답 전체와 초기 정정이 남는 것을 확인했다.

새 대화에서는 사용자가 소유했던 파란 머그를 현우에게 선물한 정정을 23번째 문답에서 정확히 회상했다. 비슷한 표현인 ‘파랑’은 현우의 자전거로 구별했고 마지막 인물별 요약도 정확했다. 새 세션에서는 기존 장기 기억을 직접 수정해야 한다고 설명했다.

### 말투·정직성에서 남은 점

- 반말↔존댓말 전환, 짧은 공감, 창작 수정, 알람·메시지·일정 제어 불가 설명은 대체로 적절했다. 한국어 조사와 문장 연결도 자연스러운 편이었다.
- 소개나 확인에서 사용자 말을 다시 요약하는 습관이 남는다. 충전·배터리 같은 위로 비유도 상투적이다. `heldout-05`, `heldout-19`에 반복이 있다.
- `single-07`은 양쪽 모두 실제 차 취향이 없음을 말했지만 요청하지 않은 가상 취향 설정을 제안했다. 부분 충족으로 남겼다.
- `long-23` 재작성은 수정 전 동일 문장 반복에서 수정 후 실제 재작성으로 바뀌었지만, 이 지점은 문맥 선택 동작이 같으므로 코드 수정의 효과로 단정하지 않는다.
- 수정 후 `long-12`는 예정인 저녁 메뉴를 현재 장면처럼 표현했고, `long-31`은 불필요한 ‘언니 또는 오빠’를 덧붙였다. 핵심 사실 실패와 구분해 주의점으로 남겼다.
- 질문 반복을 줄이려고 모든 질문을 금지하지 않았다. 친구 갈등처럼 정보가 필요한 상황의 후속 질문은 적절하다고 평가했다. 이번 변경에서 페르소나나 답변 후처리는 바꾸지 않았다.

## 실행 검증과 다음 범위

Windows 자동 검사 11개 통과: 20문답 이후 초기 정정 보존, 24,000자 초과 시 완전한 쌍·누락 고지, 단일 초대형 쌍에서 단절된 과거를 붙이지 않는 동작, 기존 기억·키 암호화·HTTP 보안·스트리밍 완료 저장 검사를 포함한다. 긴 실제 생성은 Terra만 실행했다. Sol·Luna에 대한 이번 긴 대화 비교, 여러 번 반복한 통계 검증은 하지 않았다.

24,000자를 넘는 장기 대화에서는 여전히 오래된 사실이 제외된다. 누락 고지는 단위 검사로 검증했으며 그 경계의 실제 API 품질은 이번 114회에 포함되지 않는다. 다음 우선순위는 중요한 정정을 출처·주체·시점과 함께 보존하는 요약/검색을 별도 비교하는 것이다. 자동 장기 저장은 사용자의 수정 의도와 일시 정정을 구분해야 하므로 이번에는 추가하지 않았다.

기존 로컬 CHLOE 작업 트리는 `86f70e35337353b12f067f6e0fa6ecd2994c2e49`에서 깨끗한 상태를 유지했다. Android 코드, 4B 모델, 2B adapter는 변경하지 않았다. 재학습·파인튜닝 호출은 0회다.

사용자 GPT 서버만 연결이 없는 상태에서 재시작했다. 재시작 전 SQLite 백업을 Git 제외 폴더에 남겼고, 전후 settings·sessions·messages·memories·lessons·requests 6개 테이블과 암호화 키의 해시가 동일했다. 브라우저 새로고침 후 학습실·API 키 등록 상태가 정상 표시됐다. 시험은 별도 DB에서 실행했으므로 메인 앱의 사용량 숫자에는 이번 시험 비용이 합산되지 않는다. API 계정 화면과 별도 시험 집계를 함께 확인했다.
