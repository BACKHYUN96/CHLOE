# GPT API용 클로이 PC 앱

한국어 채팅, 사용자가 편집하는 장기 기억, 말투 피드백·예시를 제공한다. Python 표준 라이브러리로 실행하는 PC 브라우저 앱이다. 기본 모델은 GPT-6.1 Terra이며 Sol과 Luna도 선택할 수 있다.

## 실행

Python 3.10 이상이 설치된 Windows에서 `Open-Chloe.cmd`를 더블클릭한다. 서버는 백그라운드에서 실행되며 기본 브라우저가 열린다. 추가 Python 패키지 설치는 필요 없다.

- 대화 화면은 http://127.0.0.1:8768/#chat 이다.
- 말투 학습실은 http://127.0.0.1:8768/#studio 이다.
- API 설정은 http://127.0.0.1:8768/#settings 이다.
- 브라우저를 닫아도 서버는 실행 상태를 유지한다. PC 재부팅 후에는 실행 파일을 다시 연다.

직접 실행할 때는 아래 명령을 쓰고 종료할 때 Ctrl+C를 누른다.

```powershell
python server.py
```

기본 포트가 이미 다른 프로그램에서 쓰이고 있으면 `python server.py --port 8770`처럼 별도 포트를 지정하고 그 주소로 접속한다.

## API 키와 모델

[OpenAI API 키 화면](https://platform.openai.com/api-keys)에서 크레딧이 지급된 조직의 프로젝트 키를 만든다. 앱의 API 설정에 입력하고 저장한 뒤 연결 확인을 누른다. 연결 확인은 모델 목록을 조회한다. 모델 목록에 보여도 실제 생성 권한이나 잔액 제한으로 요청이 실패할 수 있다.

선택한 키 저장 방식이 Windows 암호화 저장이면 현재 Windows 사용자에게 연결된 DPAPI로 보호한다. 저장 옵션을 끄면 현재 프로세스 메모리에서만 사용한다. `OPENAI_API_KEY` 환경변수도 지원하며 시작할 때 저장 키보다 우선한다. 앱에서 키를 제거해도 외부에서 설정한 환경변수는 별도로 관리해야 한다.

| 모델 | 기본 추론 설정 | 입력 / 출력 100만 토큰당 USD | 선택 기준 |
| --- | --- | --- | --- |
| GPT-6.1 Terra | none | 1 / 5 | 일상 대화 기본값 |
| GPT-6.2 Sol | low | 2 / 10 | 복잡한 맥락 비교 |
| GPT-6 Luna | none | 0.10 / 0.50 | 비용을 우선한 비교 |

가격은 2026-11-19 표준 짧은 문맥 요금 기준이다. 이번 6문항씩의 실측에서 Luna가 다른 앱 이름을 혼동한 사례가 있었다. 모델별 첫 응답 시간과 실제 답변은 검증 기록을 참고한다. [공식 가격표](https://developers.openai.com/api/docs/pricing) · [실행 검증](verification-20261119.md)

## 기억과 말투

현재 대화의 성공적으로 완료된 사용자·assistant 쌍을 SQLite에 저장한다. 다음 요청에는 합계 24,000자 이내의 최근 완전한 대화 쌍을 넣는다. 그보다 오래된 원문은 현재 질문·최근 문맥과 관련된 문답, 명시적 정정, 짧은 문답을 찾아 **별도 최대 12,000자**의 발췌로 함께 보낸다. 발화자·문답 순서·원문을 보존하며 요약으로 사실을 새로 만들거나 장기 기억을 자동 수정하지 않는다. 이력의 문자 예산은 최대 36,000자이며 설정·장기 기억·현재 질문·안내 문구는 별도다. 토큰 수와 일치하는 단위는 아니다.

검색은 PC에서 실행되므로 별도 요약·임베딩 API 호출은 없다. 대신 발췌가 추가된 만큼 응답 요청의 입력 토큰과 비용이 늘 수 있다. 모든 과거 사실을 항상 찾는 것은 아니다. 누락 범위는 모델에 알리고 DB 원문은 삭제하지 않는다. 새 대화에는 다른 세션의 원문을 자동 전달하지 않는다. 기존 장기 기억의 사실을 바꾸려면 기억 화면에서 해당 항목을 수정한다.

장기 기억은 기억 화면에서 대상과 사실을 작성하거나, 사용자 메시지 아래의 ‘기억에 추가’를 눌러 저장한다. 다음 대화에서도 쓸 사실을 직접 검토·수정·삭제할 수 있다. 기억은 최대 40개, 항목당 사실 500자다. 새 대화에는 저장한 기억을 모두 참고 자료로 전달하고, 답변에서는 관련 사실만 활용하도록 지시한다. 관련성 판단과 사실 이해에는 모델 오류가 남을 수 있다.

말투 학습실에는 피드백을 최대 20개 저장할 수 있다. 질문·좋은 답변 예시를 함께 추가할 수 있으며 다음 요청의 지침에 반영한다. 응답 아래의 ‘말투 피드백’으로 예시를 가져와 편집할 수 있다. 연습 버튼은 실제 API 요청을 보낸다. 이 화면의 ‘학습’은 피드백과 예시를 저장하는 기능이며 가중치 파인튜닝 작업을 생성하지 않는다.

## 데이터와 실행 범위

사용자 데이터는 이 폴더의 Git 제외 디렉터리 `.data/`에 보관한다. `chloe.sqlite3`에 대화·기억·말투·성공 요청의 사용량이 저장되고, 선택적으로 `api-key.dpapi`에 암호화된 키가 저장된다. 대화 시 최근 대화와 저장한 기억·말투 자료는 OpenAI API로 전송된다. Responses 요청은 `store=false`를 사용한다. OpenAI 측 데이터 처리는 계정과 API 정책에 따른다.

서버는 `127.0.0.1`에서만 요청을 받고 Host·Origin과 변경 요청 토큰을 검사한다. 키를 브라우저 응답이나 애플리케이션 로그에 반환하지 않는다. 입력·출력은 HTML로 실행하지 않고 텍스트로 표시한다. 키와 개인 데이터는 Git에 포함하지 않는다.

답변은 스트리밍하며 완료가 확인된 경우에만 사용자·assistant 쌍과 사용량을 한 트랜잭션으로 저장한다. 실패·불완전 응답은 다음 대화 이력에 포함하지 않는다. 중복 요청 ID를 거부하며 자동 재시도를 하지 않는다. 연결이 끊기면 왼쪽 대화를 다시 열어 저장 여부를 확인한다.

이 앱의 추정 비용은 성공 응답의 입력·출력·캐시 토큰에 표의 단가를 적용한다. 실패·중단 요청과 다른 앱의 사용량, 향후 가격 변경은 반영되지 않을 수 있다. 계정의 실제 잔액은 OpenAI 결제 화면에서 확인한다. 첫 응답 시간은 첫 텍스트 조각이 도착할 때까지 측정한다.

## 검증

```powershell
python -m unittest -v test_app.py
```

키가 설정된 상태에서 합성 6질문을 각 모델에 실제 요청한다. 이 명령은 API 요금이 발생하며 새 결과 경로를 요구한다. 임시 데이터베이스를 사용해 사용자의 대화·기억을 변경하지 않는다.

```powershell
python smoke_api.py --key-dir .data --output .data/new-verification.jsonl
```

이 버전은 텍스트 대화용 PC 앱이다. 음성 입력·TTS·알람 설정·검색 도구는 구현 범위에 포함되지 않았다.

### 긴 대화와 새 질문 비교

[114회 실제 응답 비교와 직접 평가](evaluation/long-dialogue-20261119.md)에 수정 전후·새 26문답의 원문과 비용을 기록했다. 재실행은 API 비용을 사용한다. 실제 사용자 DB를 수정하지 않고 새로운 출력 폴더에 합성 시험 DB를 만든다. 출력 경로는 기존 폴더를 덮어쓸 수 없다. 비용 한도는 응답 토큰 기반 추정이며 계정 청구 한도를 변경하지 않는다.

[24,000자 초과 이력의 추가 38회 비교](evaluation/archive/report-20261119.md)는 약 6.2만~6.7만 자 합성 이력으로 원문 검색과 정정 보존을 검증한다. 긴 이력은 시험용으로 작성해 넣은 자료이며 전부 API로 생성한 대화가 아니다. 평가 질문과 후속 응답 38개만 실제 API 생성이다.

```powershell
python evaluate_dialogue.py --implementation server.py --suite evaluation/long-dialogue-suite.json --key-dir .data --output .data/new-long-dialogue --max-estimated-usd 1
```

긴 이력 검색 재검증은 위 명령의 suite를 `evaluation/archive/same-questions.json` 또는 `evaluation/archive/unseen-questions.json`으로 바꾸고 새 output 경로를 지정한다.
